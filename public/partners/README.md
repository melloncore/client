# Partner logos

These SVGs are PLACEHOLDERS (brand-coloured text), not the real logos.
Replace each file with the official logo from the brand's partner portal / press kit,
keeping the same file name (hp, dell, lenovo, huawei, microsoft, camunda .svg). PNG/WebP also works:
change the extension in `partners` in src/content/site.ts.
Follow each brand's logo-usage guidelines (clear space, no recolouring).
